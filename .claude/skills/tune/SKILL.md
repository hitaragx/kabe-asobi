# その場で直す

子どもが待っているので、速さが最優先。説明は後でよい。

## 判断の順番

1. **params で済むか**：`list_games` で、いま壁に出ている遊びの調整できる値を見る（`value` がいまの値、`default` が元の値。倍率は `value` にかける）
   - 済むなら `set_params`（1秒で反映。min〜max の外の値は自動で中に収まる。返事が「遊びが壊れた」なら `reset_params` で戻す）。例：「大きく」→ size を 1.3〜1.5 倍、「ゆっくり」→ speed を 0.6〜0.7 倍
   - 変えすぎない。1回の変更は 1.5 倍まで。もっと、と言われたらまた変える
2. **済まないとき**：下書き `web/games/<id>.ts` を直し、`verify_game` → `publish_game`（`reason` に、何をなぜ直したかを1〜2文）
   - 次からは params で直せるよう、その値を params に出しておく
3. **区画**：場所ごとに変えたいときは `set_zones`（的を出すときに `ctx.zone` を使う遊びで効く。見本の遊びはいずれも対応。効かないときは下書きで `ctx.zone`／`ctx.zoneRect` を使うように直す）。区画の名前は子どもにも見えるので、やさしい言葉にする（「ちいさい子」「おおきい子」など）。やめるときは zones を空の配列で
4. **戻す**：「さっきのがいい」→ 値を変えたなら `reset_params` か `set_params` で元の値、コードを変えたなら `rollback_game`、遊びを変えたなら `previous_game`

## よくある頼みごと

| 職員の言葉 | 直し方 |
|---|---|
| 大きく／小さく | size |
| ゆっくり／速く | speed |
| 小さい子の側だけ簡単に | `set_zones` で区画に分ける。例：左半分 `{x0:0,y0:0,x1:0.5,y1:1,size:1.5,speed:0.6,label:"ちいさい子"}`、右半分 `{x0:0.5,y0:0,x1:1,y1:1,label:"おおきい子"}` |
| 車いすの子・背の低い子がいる | `set_zones` で下の帯（例 y0:0.5〜y1:1）を大きくゆっくりにし、label を付ける。高さの値（row・top/bottom など）があれば、それも下げる |
| 的を下に | row など高さの値。なければ下書きで出現位置を画面の下半分に |
| 点数はいらない | showCount / showPercent などを false |
| 音楽を小さく／止めて／音を大きく | `set_audio`。music（音楽）・sfx（効果音）は 0〜10。1回に2〜3段まで。止めるは music:0 |
| 曲を変えて（和風に、にぎやかに など） | `set_audio` の styles で、いまの遊びの ID に雰囲気を指定（nonbiri／nigiyaka／wa／fushigi／kirakira／none） |
| 対戦にして（小学生） | 新しい遊びとして作る（new-game スキル）。左右のチームで、それぞれの側に当てた数を競う |
