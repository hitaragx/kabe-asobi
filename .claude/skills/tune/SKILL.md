# その場で直す

子どもが待っているので、速さが最優先。説明は後でよい。

## 判断の順番

1. **params で済むか**：`list_games` で、いま壁に出ている遊びの調整できる値を見る
   - 済むなら `set_params`（1秒で反映）。例：「大きく」→ size を 1.3〜1.5 倍、「ゆっくり」→ speed を 0.6〜0.7 倍
   - 変えすぎない。1回の変更は 1.5 倍まで。もっと、と言われたらまた変える
2. **済まないとき**：下書き `web/games/<id>.ts` を直し、`verify_game` → `publish_game`
   - 次からは params で直せるよう、その値を params に出しておく
3. **戻す**：「さっきのがいい」→ 値を変えたなら `reset_params` か `set_params` で元の値、コードを変えたなら `rollback_game`、遊びを変えたなら `previous_game`

## よくある頼みごと

| 職員の言葉 | 直し方 |
|---|---|
| 大きく／小さく | size |
| ゆっくり／速く | speed |
| 的を下に（車いすの子・小さい子） | row など高さの値。なければ下書きで出現位置を画面の下半分に |
| 小さい子の側だけ簡単に | 下書きで、画面の左右など区画ごとに大きさ・速さを分ける |
| 点数はいらない | showCount / showPercent などを false |
| 対戦にして（小学生） | 新しい遊びとして作る（new-game スキル）。左右のチームで、それぞれの側に当てた数を競う |

## 伝え方

反映したら一言だけ：「大きくしました。どうですか？」
