# 壁への合わせ込み

職員の作業は「光った丸を順にタッチする」だけにする。計算と確認は Claude がする。

## 手順

1. `wall_status` で、センサーが `ok` か、壁の画面が開いているかを見る
   - センサーが `lost`：「センサーの電源とケーブルを確かめてください」と伝える（docs/sensor-setup.md）
2. 職員に伝える：「これから壁に丸が出ます。光った丸を、手でタッチして少し押さえてください。全部で6回です」
3. `calibrate_start`
4. `calibrate_status` を数秒おきに見る。進まないときは：
   - `sensor_objects` で何かをとらえているか見る。何もない → 手が走査の面に届いていない（壁にしっかり触れてもらう）
   - 物がたくさんある → 壁の前に人や物がある。下がってもらう
5. 結果
   - `done`：「合わせ込みができました（ずれ〇cm）」と伝える
   - `failed`：`checkErrorsCm` と `fitErrorsCm` を見る。1つだけ大きいなら `calibrate_redo`（その番号）。全体に大きいなら、センサーが動いた・押さえる間に手が動いた可能性。もう一度 `calibrate_start`
6. 最後に `test_hit` ではなく、職員に実際に的を当ててもらい、ずれないか確かめる

## 合格の目安

ずれ 5cm 以下（成功基準）。柔らかいボールの直径が7cmほどなので、これより小さければ遊びに困らない。
