# センサーの当たり検出を調整する

推測で値を変えない。必ず「記録を流して数える → 1〜2個だけ変えて数え直す → 良くなったら反映」の順で進める。

## 1. 様子を見る

1. `wall_status` でセンサーが `ok` か確かめる
2. `sensor_tuning` で、いまの値と意味を見る
3. `list_recordings` で記録を探す。なければ職員に頼んで記録する（docs/sensor-setup.md の「記録する」：最初の10秒は誰も壁に近づかない、四隅をタッチ、ボールを当てる、人が横切る）

## 2. 数える

`analyze_recording` を、いまの値のまま呼ぶ（誰もいない時間が分かっていれば `quietSec` を渡す）。

見るところ：

| 症状 | 数字 | 調整の向き |
|---|---|---|
| 当ててないのに反応する | `quietFalseDowns` が 0 でない | `foregroundThresholdMm` を上げる、`minPoints` を上げる。場所が決まっているなら `ignoreRects` |
| 1回なのに2回数える | `suspectedDoubles` が多い | `clusterGap` を上げる（物が分かれている）、`lostMs` を上げる（一瞬見失っている） |
| 当てたのに反応しない | 模擬なら `truth.recall` が低い。本物なら、当てた回数より `downs` が少ない | `minPoints` を下げる、`foregroundThresholdMm` を下げる |
| 人や家具に反応する | `lingering` に幅0.2m以上の物、`widthM.p90` が大きい | `maxWidth` を下げる（ボール・手は0.1m前後）。動かない物なら `ignoreRects` |
| 壁の外の物に反応する | `downsAll` が `downs` よりずっと多い | 遊びには届かないので急がない。気になるなら `maxDistance` |

目安：ボールは続く時間が50〜150ms・幅約0.07m、手のタッチは数百ms・幅0.05〜0.1m、人の体は幅0.2m以上。

## 3. 試す

- `analyze_recording` に `values` を渡して、変えた場合の数字を見る。一度に変えるのは1〜2個
- 良くなったか：誤反応・二重が減り、拾える数が減っていないこと
- 2〜4通り試して、一番よいものを選ぶ

## 4. 反映する

1. `sensor_tuning_set` で値を変える（すぐ効き、保存される）
2. センサーや家具を動かしたときは `sensor_relearn`（職員に「1秒だけ壁の前から離れてください」と伝えてから）
3. 職員に実際にボールを当ててもらい、`wall_status` の直近10秒の当たりの数を見て確かめる

## 伝え方（職員に）

数字は見せず、何を直したかを一言で：「人が壁の近くに立っても反応しないようにしました。ボールを当ててみてください」
