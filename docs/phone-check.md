# スマホ実機（iPhone Safari）の確認項目

11/6（金）夜に自宅で確認する。画面なしのブラウザ（Chromium）では確認済みで、iPhone の実機ではまだ確かめていない。
結果は項目ごとに ○／× と気づいたことを PROGRESS.md に書く。× のものは、土曜の撮影までに直すか、撮影で避ける。

## 準備

- [ ] Mac と iPhone を同じ Wi-Fi につなぐ（ゲスト用の Wi-Fi は、端末どうしが通信できないことがあるので避ける）
- [ ] `npm run dev`（センサーをつないだら `npm run dev:lidar`）で起動し、表示された「同じ Wi-Fi のスマホから」の URL を使う
- [ ] 初めてのとき、Mac に「受信接続を許可しますか」と出たら「許可」（出ないのにつながらないときは、システム設定 → ネットワーク → ファイアウォールを見る）
- [ ] 撮影の日は合言葉を固定する（起動のたびに変わると、職員役のスマホで開き直しになる）：`npm run phone -- --key <好きな合言葉>`

## 1. つながる・開ける

- [ ] URL（合言葉つき）を Safari で開ける
- [ ] 一度開いたあと、合言葉なしの URL でも開ける（24時間は覚えている）
- [ ] 合言葉が違う URL では開けない
- [ ] 「ホーム画面に追加」して、そこから開ける（撮影で URL バーが映らない）

## 2. 見た目

- [ ] 文字が小さすぎない。ボタンが指で押しやすい（親指で届く）
- [ ] 画面の上下（ノッチ、ホームバー）にボタンや文字が隠れない
- [ ] 縦向きで崩れない。横向きにしても使える
- [ ] 壁の今の画面（小さな画像）が 1〜2秒ごとに変わる
- [ ] 下から出る画面（遊びの一覧、壁に合わせる）が開いて、閉じられる。後ろの画面がスクロールしない

## 3. 頼みごと（本物の Claude）

- [ ] 文字で打って送れる。日本語の変換中に Enter を押しても、勝手に送られない
- [ ] 送ったあと「作業中」の表示と、途中の経過（いま何をしているか）が出る
- [ ] 返事が少しずつ出てくる（最後にまとめて出るのではない）
- [ ] 1〜2分かかる頼みごと（新しい遊び）の間、画面を開いたままにしても途中で切れない
- [ ] 途中で「止める」を押すと止まる
- [ ] 候補のボタン（もっと大きく、ゆっくりに など）を押すと、その言葉で頼める
- [ ] 画面を消して（スリープ）戻ってきたとき、表示が今の状態に戻る（作業中だった頼みごとの結果が見られるか）

- [ ] 初めて開いたとき（会話が空のとき）、頼み方の例が4つ出る。押すとそのまま頼める
- [ ] 新しい遊びを頼むと、作る前に案のカードが出る。「なおしたい」で直す言葉を入れられ、「これで作って」で作り始める
- [ ] 「これで作って」を押すと、壁の左下に「つぎの あそびを つくってるよ」が出て、壁に出たら「できた！」に変わって消える
- [ ] 「もっと大きく」などの調整は、案を出さずにすぐ直る

## 4. 声で頼む

- [ ] マイクのボタンで、話した言葉が文字になる（iPhone の設定で「Siri」または「音声入力」がオンになっている必要がある）
- [ ] 初回のマイクの許可が出て、許可すると使える
- [ ] 「4歳くらいの子が10人います。節分なので、鬼にボールを当てる遊びを作って」が正しく文字になる（「節分」「鬼」などの言葉）
- [ ] 話し終わると自動で送られる。聞き間違えたまま送られることが多くないか（多ければ、送る前に確かめる作りに変える）
- [ ] 声が使えないときに、案内（キーボードのマイクを使う、など）が出る
- [ ] 代わりに、キーボードのマイク（音声入力）でも頼める

## 5. ボタンの操作

- [ ] 「さっきのに戻して」で、前の遊びに戻る
- [ ] 遊びの一覧から選ぶと、壁が変わる
- [ ] 「そのほか」から「おと」「きろく」「壁に合わせる」「新しい会話にする」が開ける
- [ ] 「壁に合わせる」を始めると、壁に丸が出て、スマホに進み具合が出る。やめることもできる

## 6. 困ったとき

- [ ] Mac 側のハブを止めると、スマホに分かる表示が出て、再び動かすと戻る
- [ ] Wi-Fi を一度切ってつなぎ直しても、開き直せば続きから使える
- [ ] 費用の上限（1回 $3）に近い頼みごとで、分かるメッセージが出る（確認は任意。費用がかかる）

## 7. 撮影のために

- [ ] iPhone の画面収録（コントロールセンター）で、スマホの画面を録れる。通知は「おやすみモード」で止める
- [ ] 画面収録に、合言葉つきの URL が映らない（ホーム画面から開く）
- [ ] 文字の大きさが動画で読める（3分割の1枠に縮めても読めるか）
