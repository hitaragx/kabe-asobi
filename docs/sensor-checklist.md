# センサーをはじめてつなぐ日のチェックリスト

スマホで見ながら進める1枚。くわしい説明は [sensor-setup.md](sensor-setup.md)。
全部で40分〜1時間の見込み（⑥の合わせ込みは、プロジェクターがあるときだけ）。

## 持ち物

- [ ] 測域センサと電源（AC アダプタ）
- [ ] USB-C の LAN アダプタと LAN ケーブル
- [ ] PC（このリポジトリが入っているもの）
- [ ] 柔らかいボール（1〜3個）
- [ ] センサーを壁に付けるもの（養生テープ、台など）
- [ ] （あれば）短焦点プロジェクターと HDMI ケーブル

## ① つなぐ（5分）

- [ ] センサーに電源をつなぎ、ランプが緑になるのを待つ
- [ ] センサー → LAN ケーブル → LAN アダプタ → PC
- [ ] PC の有線 LAN の IP を設定する：`192.168.0.100`／`255.255.255.0`／ルーターは**空欄**

## ② 確かめる（5分）

```bash
ping -c 3 192.168.0.10       # Windows では ping -n 3 192.168.0.10
npm run sensor:check
```

**うまくいったとき**：最後に次のように出ます。

```
3. 仕様：UST-20LX、1081点、1点 0.250°、1回 25.0ms、60〜20000mm
4. 距離：1081点中 ○点が測れました（○%）。いちばん近い物まで ○mm、正面 ○mm
合格：センサーとの通信は問題ありません
```

**だめなとき**

| 出ること | 見る所 |
|---|---|
| ping に返事がない | ケーブル、ランプ、PC の IP（①）。それでもだめなら、センサーの IP が変わっているかもしれない（[sensor-setup.md の 2.](sensor-setup.md#2-確かめる5分)） |
| ping は返るが「不合格」 | もう一度 `npm run sensor:check`。続くときは、表示をそのまま Claude に送る |
| 「測れた点が少ないです」 | センサーの前に何もない（遠すぎる）。壁に向けて置けば直る |

## ③ 置く（10分）

- [ ] 投影する範囲の**上の辺の中央、少し上**に付ける。走査の面が壁と平行になるように（壁から数cm離す）
- [ ] センサーの正面が下（床の方）を向くように
- [ ] 走査の面に、家具やカーテンがかからないように

## ④ 記録する（15〜20分）

```bash
npm run record -- 2026-11-06-a
```

10秒ごとに、次のように出ます。

```
[0分00秒] センサーにつながりました。記録を始めます
[0分01秒] センサーの様子：正常
[0分10秒] 記録中：400回分のスキャン ／ この10秒の当たり 0回（合計 0回）
[0分20秒] 記録中：800回分のスキャン ／ この10秒の当たり 3回（合計 3回）
```

- スキャンは10秒で約400回増えれば正常
- **誰も壁に近づいていないのに「当たり」が増える**ときは、走査の面に何かがかかっている（③を見直す）。そのままでも記録は続けてよい（あとで調整に使う）
- **タッチしても当たりが増えない**ときは、手が走査の面に届いていない。壁にしっかり触れる

次の順に動きます（それぞれ声に出して言っておくと、あとで分けやすい）。

| 順 | すること | 時間 |
|---|---|---|
| 1 | 誰も壁に近づかない（背景を覚える） | 10秒 |
| 2 | 投影範囲の四隅と中央を、順に手でタッチ（各2秒） | 20秒 |
| 3 | 手で壁をなぞる（左右・上下） | 20秒 |
| 4 | 柔らかいボールを壁に当てる（1人で、いろいろな場所に30回） | 1分 |
| 5 | 2〜3人で同時にボールを当てる（1人なら、両手やボール2個で） | 1分 |
| 6 | 壁の前を横切る、壁の近くに立つ | 30秒 |

止めるときは Ctrl+C。「記録を終えました」と出れば保存できています。

## ⑤ 記録を確かめる（5分）

```bash
npm run hub -- --source replay --file recordings/2026-11-06-a.jsonl
```

別のターミナルで `npm run web` を動かし、ブラウザで `http://127.0.0.1:5173/?debug=1` を開くと、当たった場所が出ます（合わせ込みの前なので、位置はずれていてよい）。

## ⑥ 壁に合わせる（プロジェクターがあるとき、10分）

- [ ] プロジェクターを PC につなぎ、壁に映す
- [ ] `npm run dev:lidar` で起動し、壁の画面を全画面にする（Mac は 表示 → フルスクリーン、Windows は F11）
- [ ] スマホで「そのほか」→「壁に合わせる」。光った丸を順にタッチして、少し押さえる（6回）
- [ ] 「ずれ ○cm」が **5cm 以下**なら合格
- [ ] 遊びを1つ出して、ボールを当てて確かめる

センサーの IP が `192.168.0.10` でないときは、`npm run dev:lidar` の代わりに、3つのターミナルで次を動かします。
`npm run hub -- --source lidar --host <IP>`／`npm run web`／`npm run phone`

## ⑦ 終わったら Claude に送るもの

- `npm run sensor:check` の表示
- 記録の名前（例：`2026-11-06-a`）と、気づいたこと（勝手に反応した、反応しなかった、など）
- 合わせ込みをしたなら、「ずれ ○cm」

記録を Claude が分析して、当たりの見つけ方をその場所に合わせて調整します（`sensor-tune`）。
